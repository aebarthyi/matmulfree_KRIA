# Host-side requirements for `mmfree_pack` — the weight packer that turns a model blob
# (or an HF checkpoint) into the engine's per-port resident weight slices + manifest.
# This is the ONLY Python left in the integration layer; the board runs C/C++ only.
#
#   python3 -m pip install -r requirements.txt
#   python3 -m mmfree_pack.cli --blob <model.mmfree> --out-dir packed/ --manifest <preset.env>
#
# numpy is all the packer needs for the common path (--blob), because the ternary
# quantization already happened upstream in matmulfreellmCPU/tools/provision.py.
numpy

# Only for `--checkpoint <hf-id>`, i.e. packing straight from a checkpoint instead of a
# blob. Both are imported lazily (mmfree_pack/model.py), so the --blob path never loads
# them and does not need them installed. A CPU-only torch is enough:
#   pip install torch --index-url https://download.pytorch.org/whl/cpu
torch          # optional
safetensors    # optional (checkpoint format)
